# ItsDrDan Video Finder — Finished Transcript Version

Includes:
- automatic public channel library updates;
- automatic English VTT transcript attempts;
- transcript searching with timestamp matches;
- clickable full transcript below the large video player;
- fixed player overlay so selected videos are visible;
- automatic GitHub Pages deployment.

Keep:
Settings → Pages → Source → GitHub Actions

Run:
Actions → Update ItsDrDan videos and transcripts → Run workflow

Use transcript/caption limit 20 for the first backfill run.
